# AI 오피스

Claude · GPT · Gemini 가 **한 공간에서 함께 일하는** 웹앱입니다.
설치할 것이 없습니다. Windows 기본 기능만으로 돌아갑니다.

---

## 실행 방법

**`시작하기.bat`** 을 더블클릭하세요.

검은 창이 하나 뜨고, 브라우저에서 `http://localhost:8787` 이 자동으로 열립니다.
그 검은 창은 서버입니다 — **닫으면 앱도 멈춥니다.** 다 쓰면 닫으세요.

> `index.html` 을 직접 더블클릭해도 화면은 뜨지만, 브라우저 보안(CORS) 때문에
> AI 호출이 실패합니다. 반드시 `시작하기.bat` 으로 실행하세요.

## 처음 한 번: API 키 넣기

오른쪽 위 **🔑 API 키** 버튼을 누르고, 쓰고 싶은 AI의 키를 붙여넣으세요.
셋 다 넣을 필요는 없습니다. 하나만 있어도 동작합니다.

| AI | 키 발급처 | 키 형태 |
|---|---|---|
| Claude | https://console.anthropic.com/settings/keys | `sk-ant-...` |
| GPT | https://platform.openai.com/api-keys | `sk-...` |
| Gemini | https://aistudio.google.com/apikey | `AIza...` |

키는 **이 브라우저 안에만** 저장됩니다(localStorage). 서버로도, 저에게도 전송되지 않습니다.
다른 사람이 쓰는 PC라면 다 쓴 뒤 **전체 삭제**를 눌러주세요.

> 각 AI 호출은 해당 회사에 **사용료가 과금**됩니다. 라운드 수를 늘리거나 참가자를 늘리면
> 그만큼 호출 수가 곱해집니다.

## 네 가지 협업 모드

### 🗣 회의실
참가자들이 **순서대로 발언**합니다. 각 AI는 앞사람들의 발언을 모두 읽은 상태로 말하므로
동의·반박·보완이 실제로 이어집니다. **라운드**를 2~3으로 올리면 여러 바퀴 토론합니다.

> 안건을 던지는 사람(당신)이 사회자입니다.

### 🔀 파이프라인
왼쪽 목록의 **위에서 아래 순서대로** 작업이 넘어갑니다.
1번이 만든 결과물을 2번이 이어받아 다듬고, 3번이 또 다듬습니다.
참가자 순서 = 작업 순서이므로, 역할을 "기획 → 작성 → 검토" 처럼 짜두면 좋습니다.

### 📄 작업공간
오른쪽 **공유 문서**를 모든 AI가 함께 보고 고칩니다.
AI가 문서를 갱신하면 오른쪽 패널에 즉시 반영됩니다. 당신이 직접 타이핑해도 됩니다.

### ⚖ 1:1 비교
**같은 질문을 모두에게 동시에** 던지고 답변을 나란히 놓습니다.
어느 모델이 이 문제에 강한지 볼 때 쓰세요.

## 참가자 편집

왼쪽 패널에서:
- **참여중 / 대기** — 이번 작업에 넣을지 뺄지
- **설정** — 이름, 모델, 역할(시스템 프롬프트), 색상
- **+ 참가자 추가** — 같은 AI를 역할만 다르게 여러 명 넣어도 됩니다
  (예: Claude를 "작성자"와 "비평가" 두 명으로)

**역할 프롬프트가 결과를 좌우합니다.** 기본값보다 구체적으로 쓸수록 좋아집니다.

모델명은 목록에 없어도 **직접 입력**할 수 있습니다. 새 모델이 나오면 이름만 바꿔 넣으세요.

## 기타

- **사고수준** — Claude 계열에만 적용됩니다. 낮음=빠르고 저렴, 높음=느리고 정확.
- **⬇ 저장** — 대화 전체 + 공유 문서를 마크다운 파일로 내려받습니다.
- **🌗** — 밝은/어두운 테마.
- **Ctrl+Enter** — 전송.
- 대화·문서·참가자 설정은 브라우저에 자동 저장되어 다음에 열어도 남아 있습니다.

## 문제가 생기면

| 증상 | 원인 / 해결 |
|---|---|
| 검은 창이 바로 닫힘 | 포트 8787을 다른 프로그램이 쓰는 중. `start.ps1` 의 `$port` 를 8788 등으로 변경 |
| `HTTP 401` | API 키가 잘못됨. 다시 복사해 넣으세요 |
| `HTTP 404` | 모델명 오타이거나 해당 계정에 그 모델 권한이 없음 |
| `HTTP 429` | 요청 한도 초과. 잠시 후 재시도 |
| 응답이 안 옴 | 결제 수단 미등록 계정이면 API가 막혀 있을 수 있습니다 |
